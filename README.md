# TP3 : Contrôle d'accès à la base de données

Gestion des utilisateurs, privilèges, profils et rôles sous Oracle.

## Contenu
- Création de tablespaces et d'utilisateurs (`DBAGRICOL`, `Admin`)
- Privilèges système et privilèges objet (`GRANT`, `REVOKE`)
- Vues et index sur les tables d'un autre schéma
- Profil `AGRICOL_Profil` (limites de ressources et mots de passe)
- Rôle `MARCHE_MANAGER`

## Fichiers
- `tp3.sql` : commandes du TP, numérotées comme dans l'énoncé

Remplacer `<CDB>` et `mdp` avant d'exécuter le script.
